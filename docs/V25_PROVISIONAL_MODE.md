# v25 임시 식단 개발 모드

작성일: 2026-09-15

사용자 결정에 따라 **앱 기능 개발을 먼저 진행**한다.

## 현재 운영

- 『뿐이 토핑 이유식』 실제 일별 스케줄표는 아직 확보하지 못했다.
- 앱 기능을 먼저 개발하기 위해 2026-09-14부터 6주간 `source: provisional` 식단을 개발 데이터로 넣는다.
- 이 임시 식단은 **『뿐이』 식단이라고 표시하지 않는다.**
- `source: ppeuni_verified` 검증 규칙은 그대로 남겨 두고, v25 개발 화면에서만 `allowProvisional: true`를 명시적으로 켠다.
- 『뿐이』 스케줄표를 확보하면 `src/ppeuni-data.js`의 식단 데이터만 교체하고 준비·체크·재고 로직은 그대로 사용한다.

## 임시 식단 기준

- 도준이 기존 급여 이력에 등장한 재료 범위에서 구성한다.
- 한 끼 개발 데이터는 총 150g: 진밥 80g + 단백질 20g + 채소 15g + 채소 15g + 후식 20g.
- 목적은 영양 처방이 아니라 **1차/2차 준비량 계산, 큐브 재고 차감, 완료 체크, 재제조 알림 기능 검증**이다.

- 2차 준비: 9/17(목) → 9/18~9/20, 9끼

## 데이터 교체 원칙

『뿐이』 실제 스케줄표를 받으면 각 끼니를 다음 형태로 교체한다.

```js
{
  source: 'ppeuni_verified',
  sourceRef: '책 페이지/사용자 제공 식단표 식별자',
  title: '원문 식단명',
  ingredients: [{name:'양파', grams:20}]
}
```

임시 식단과 검증된 뿐이 식단을 데이터상 명확히 구분한다.
